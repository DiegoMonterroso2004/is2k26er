Manual de Ayuda - Mantenimiento Tipo Deporte

Formulario para registrar, modificar, consultar y eliminar tipos de deporte.

1. Descripción de la pantalla

Esta pantalla permite administrar los tipos de deporte registrados en el sistema polideportivo. Desde este mantenimiento se pueden ingresar nuevos deportes, modificar información existente, eliminar registros y consultar los datos almacenados.

2. Campos del formulario

  • ID Tipo Deporte: Identificador único del tipo de deporte.
  • Nombre Deporte: Nombre del deporte registrado, por ejemplo: Fútbol, Baloncesto, Natación, Atletismo, entre otros.

3. Botones del navegador

  • Ingresar: Habilita el formulario para agregar un nuevo tipo de deporte.
  • Modificar: Permite editar el registro seleccionado.
  • Guardar: Guarda los datos ingresados o modificados.
  • Cancelar: Cancela la operación actual.
  • Eliminar: Elimina el registro seleccionado.
  • Consultar: Permite buscar información registrada.
  • Imprimir: Genera el reporte asociado al mantenimiento.
  • Refrescar: Actualiza los datos mostrados en la tabla.
  • Inicio: Se posiciona en el primer registro.
  • Anterior: Se mueve al registro anterior.
  • Siguiente: Se mueve al siguiente registro.
  • Fin: Se posiciona en el último registro.
  • Ayuda: Abre este manual de ayuda.
  • Salir: Cierra la ventana del mantenimiento.

4. Cómo ingresar un nuevo tipo de deporte

  1. Presionar el botón Ingresar.
  2. Escribir el nombre del deporte en el campo Nombre Deporte.
  3. Presionar el botón Guardar.
  4. Verificar que el nuevo registro aparezca en la tabla inferior.

5. Cómo modificar un registro

  1. Seleccionar el registro en la tabla.
  2. Presionar el botón Modificar.
  3. Cambiar el valor del campo Nombre Deporte.
  4. Presionar el botón Guardar.

6. Cómo eliminar un registro

  1. Seleccionar el registro que desea eliminar.
  2. Presionar el botón Eliminar.
  3. Confirmar la eliminación.
  4. Presionar Refrescar para validar el cambio.

7. Recomendaciones

  • No dejar vacío el campo Nombre Deporte.
  • No registrar deportes duplicados.
  • Verificar los permisos del usuario si los botones aparecen deshabilitados.
  • Usar el botón Refrescar después de realizar cambios.
